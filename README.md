Entry for the [Two-Sentence Horror](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253) bounty on make.fun.

A stdlib-only Python program (`main.py`) that writes one original horror story
of exactly two sentences to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that is set). Deterministic: every run produces the same text.

Run it:

```sh
python3 main.py
```
